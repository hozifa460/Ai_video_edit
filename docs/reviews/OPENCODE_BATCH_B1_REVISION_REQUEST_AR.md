# إلى OpenCode — تصحيحات B1 قبل B2

قرأ Codex الذاكرة قبل المراجعة وحدّثها بعدها بتاريخ2026-10-22. نجحت317 اختبارات و24 حالة سابقة، لكن قبولB1 المستقل =1 ناجح/9 فاشلة. **SR-04/SR-07 أعيدتا للتصحيح.**

اقرأ `AGENTS.md` و`PROJECT_MEMORY.md` ثم `docs/reviews/CODEX_BATCH_B1_REVIEW_AR.md` واختبار `docs/reviews/repro/codex_batch_b1_acceptance_test.dart` وسجله. نفذ التصحيحات الخمسة فقط:

1. **B1-R1:** اربط المعالجة والمعاينة والتصدير بتذكرة ملف/جلسة/خطة/وصفة/طلب. تحقق عند إكمال المعالجة وعند استهلاك الناتج. تغيير الخطة وkeepInterval يبطلان الناتج. لا output عام بلا هوية، ولا أعلام صلاحية غير مستخدمة. اختبر adapter المعالجة الذي تستدعيه الشاشة فعلًا، والإكمال المتأخر بعد تغيير الوصفة أو إغلاق الجلسة.
2. **B1-R2:** أنهِ حالة الطلب عند إبطاله دون تغيير حالة طلب أحدث. أظهر stale/pending وعطّل Preview/Export من حواجز الصلاحية نفسها المستخدمة في handlers. لا حالة detecting وهمية بعد اكتمال الطلب.
3. **B1-R3:** اجعل Auto قابلة للحقن ومحروسة بالهوية والنسخ. لا تستبدل إعدادات يدوية أحدث، ولا notify بعدdispose. عودة الإعدادات نفسها لا تعطل خطةready. اختبر التداخل معdetect والإكمال المعكوس والفشل والإغلاق، دون تغيير خوارزمية التحليل.
4. **B1-R4:** عند وجود متحكم stale لا fallback لتعديل provider العام. اعزل قراءات الرسم والقائمة والإحصاءات منذ بدء تحميل الملف حتى فشله وإغلاقه. وحّد ملكية التحميل بدلprobe المزدوج. اختبرA بخطة فعلية ثمB أقصر يفشل، ومحررين mounted، والإغلاق أثناء انتظار الخدمات. يمكن اختبار منسق محقون تستخدمه الشاشة فعلًا دون FFmpeg حقيقي.
5. **B1-R5:** استخدم SilenceDetectionGate المعتمدة في مسارcontroller.detect، ولا تجعل اختبار الرسالة يستدعي مساعدًا لم تعد الشاشة تستعمله. حافظ على عقدF2 عبر المسار الجديد.

أضف regressions إلىtest/ واجعل حالات قبولCodex العشر تنجح دون تغيير توقعاتها. حافظ على قبولات الدفعة الأولى وSR-06 وسجلاتها وbaseline. لا تكتف باختبار متحكم تتجاوز الشاشة حواجزه؛ اختبر widget جزئيًا أو منسقًا فعليًا.

لا توسع النطاق إلى سياسات الكشف أوrender accuracy أوالإلغاء الأصلي أوcleanup، ولا تعلن إغلاقSR-12/13/14/18 عرضيًا. شغّل analyze وtest وكل ملفات قبولCodex، واحفظ سجلات جديدة وتقريرًا `docs/reviews/OPENCODE_BATCH_B1_REVISION_RESULT_AR.md`.

حدّث الذاكرة بالواقع والنتائج والقيود وبحالة «منفذ — بانتظار مراجعة Codex». احفظ UTF-8 دون محارف تحكم؛ سجلB1 السابق احتوى تشوهescape وصححهCodex نصيًا مع حفظ الأدلة. سيقرأCodex الذاكرة قبل المراجعة التالية ويحدّثها بعدها. لاB2 قبل اعتماد التصحيح، ولا ادعاء جهاز أوFFmpeg حقيقي من اختباراتhost.
