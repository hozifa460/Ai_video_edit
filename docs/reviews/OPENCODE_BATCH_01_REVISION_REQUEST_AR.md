# رسالة إلى OpenCode — تصحيح الدفعة الأولى

قرأ Codex ذاكرة المشروع قبل المراجعة وحدّثها بعدها. الدفعة الأولى تحتاج تصحيحات؛ لا تبدأ الدفعة B بعد.

اقرأ `AGENTS.md` و`PROJECT_MEMORY.md` من القرص أولًا، ثم `docs/reviews/CODEX_BATCH_01_REVIEW_AR.md` واختبار `docs/reviews/repro/codex_batch01_acceptance_test.dart` وسجله. نفّذ فقط:

1. **B01-R1 / SR-05:** أصل زمني مشترك وإزاحة صوت ذات إشارة، متسقان مع الاستخراج والكشف والقص. لا تعامل start_time المطلق كإزاحة نسبية ولا تمح القيم السالبة. اختبر البداية المشتركة غير الصفرية والصوت السابق والمتأخر.
2. **B01-R2 / SR-01:** أزل ملء الفجوات الموجبة بسماحية20ms. اجمع التداخل/التلامس الحقيقي فقط واختبر فجوات1/10/19/20/21/200ms.
3. **B01-R3 / SR-03/SR-19:** عالج القائمة الفارغة بعد فلترة union واختبر invalid-only وmixed والواجهات المفوضة لها.
4. **B01-R4 / SR-05:** ارسم waveform بمدة الصوت وإزاحته على خط الفيديو، دون تمديد الصوت إلى كامل الفيديو، مع اختبار الرسم والتلوين والبحث بالضغط.

يوصى أيضًا بـ**B01-C1**: اجعل removals/kept غير قابلتين للتعديل مع نسخ دفاعية. هذا تحسين للعقد وليس عطلًا إنتاجيًا مثبتًا. إذا أجلته فوثّق ذلك وافصل اختباره عن شروط القبول الإلزامية، دون تزوير نتيجة6 حالات الفشل الأصلية.

حافظ على إصلاح Speech Guard؛ اتجاه الانكماش داخل السكتة مطلوب ومعتمد ضمن نطاق الطلب الأصلي. اترك SR-06 وبقية البنود المفتوحة ظاهرة ولا تدع إغلاقها عرضيًا.

أضف regressions إلى `test/` تستدعي المسارات الفعلية، وشغّل analyze وtest واختبارات القبول الصريحة. لا تغير expected الصحيح لمجاراة العيب. احفظ نتائج هذه الجولة بأسماء جديدة حتى تبقى أدلة مراجعة Codex الأصلية. لا تزعم تنفيذ FFmpeg أو تزامن A/V أو حماية كلام فعلية دون وسائط وجهاز وقياسات.

سلّم `docs/reviews/OPENCODE_BATCH_01_REVISION_RESULT_AR.md` يربط كل ملاحظة بالملفات والاختبارات والقيود. حدّث ذاكرة المشروع بعد العمل، وسجّل **«منفذ — بانتظار مراجعة Codex»**. سيقرأ Codex الذاكرة مجددًا قبل كل مراجعة ويحدّثها بعدها؛ هذا طلب المستخدم الملزم لجميع النماذج. لا تمح baseline أو تاريخ الحالات.
